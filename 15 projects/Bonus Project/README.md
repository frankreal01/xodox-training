# Bonus Project Overview

This project is an **Interactive Custom 404 Error Page** built with HTML5, CSS3, and vanilla JavaScript.

### Features:
- **Intelligent Navigation**: Displays the broken requested route and provides direct navigation back to the root projects showcase.
- **Auto-Redirect Countdown**: Automatically routes the visitor back to home after 10 seconds, with interactive **Pause / Resume** controls.
- **Project Directory Search**: An instant search input with live keyword filtering across all 15 projects in the repository, preventing visitors from hitting a dead end.
- **Random Project Discovery (`🎲`)**: Jump straight into a random project from the collection with a single click.
- **Interactive Fishing Mini Easter Egg (`🎣`)**: Clicking the illustration or the "Cast Rod" button reels in humorous themed items (Code Bass, Buggy Crab, Rare Golden JS Trout, etc.).
- **Responsive Layout**: Designed to look clean, playful, and responsive across mobile, tablet, and desktop viewports.

Open `index.html` in your browser to view the custom 404 page.
