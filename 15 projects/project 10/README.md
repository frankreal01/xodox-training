# Project 10 Overview

This project is a **Pricing Cards** showcase built with plain HTML, CSS, and vanilla JavaScript. Features include:
- Interactive monthly vs. annual billing toggle with a 20% discount calculation
- Smooth animated numerical price transitions
- Interactive plan selection and accessible checkout confirmation modal
- Highlighted "Most Popular" plan badge with subtle pulse animation
- Keyboard navigation (Arrow keys and Enter/Space) for accessible browsing
- Responsive grid design tailored for all mobile, tablet, and desktop viewports
- Testimonial section with customer review and avatar

Open `index.html` in a browser to explore the pricing plans.
