# Project 11 Overview

This project is a **Team Members Showcase** application built with vanilla HTML, CSS, and JavaScript. Features include:
- Real-time search by member name, role, bio keywords, or department
- Interactive department filter tabs (All, Leadership, Design, Engineering, Marketing, Product, Support) with smooth animation
- Interactive member detail modal displaying extended bios, contact options, and clipboard copy for email
- Open positions careers modal with 1-click apply simulation and toast feedback
- Clean card hover effects with profile background gradient shifts
- Fully accessible keyboard navigation and mobile-responsive layout

Open `index.html` in a browser to meet the team.
