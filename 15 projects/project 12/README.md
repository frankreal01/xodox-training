# Project 12 Overview

This project is a **Recipe Finder App** powered by TheMealDB public REST API and built with HTML, CSS, and asynchronous JavaScript (`fetch`, `async/await`). Features include:
- Live meal search by name, ingredient, or keyword
- Responsive grid showing recipe cards with category tags and high-resolution meal thumbnails
- Detailed recipe view containing ingredients with measurements, step-by-step cooking instructions, and direct YouTube video tutorial links
- Loading states and error handling for empty queries or unfound meals
- Smooth transition back to search results

Open `index.html` in a browser to search and explore recipes worldwide.
