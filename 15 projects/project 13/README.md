# Project 13 Overview

This project is a **Currency Converter App** powered by the ExchangeRate API and built with semantic HTML5, CSS3, and modern asynchronous JavaScript (`async/await`, `fetch`).

### Features:
- **Live Real-Time Conversion**: Automatically calculates exchange values as you type or change selected currencies.
- **Currency Swapping**: Quick one-click swap button (`⇄`) to invert base and target currencies with animated transition.
- **Exchange Rate Insights**: Displays clear unit conversion rates (e.g. `1 USD = 0.92 EUR`) for reference.
- **In-Memory Caching**: Caches queried rates to reduce network overhead and ensure instantaneous response.
- **Robust Error Handling**: Gracefully handles network failures, offline status, and invalid user inputs with clear visual feedback.
- **Responsive Design**: Fully mobile-friendly layout with sleek dark-mode aesthetics and fluid controls.

Open `index.html` in your browser to run the currency converter.
