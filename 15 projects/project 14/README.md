# Project 14 Overview

This project is a **GitHub User Finder App** powered by the official GitHub REST API and built using semantic HTML, CSS, and asynchronous JavaScript (`fetch`, `async/await`).

### Features:
- **Profile Lookup**: Fetches and renders detailed user profile information (avatar, name, bio, location, join date, follower/following counts, and public repo counts).
- **Recent Repositories**: Retrieves and displays the user's latest repositories along with stargazers count, forks, language badges, and direct links.
- **Accessible & Responsive**: Fully keyboard-accessible search form (Enter key support) and a responsive dark-mode card layout.
- **Error Feedback**: User-friendly alerts when an entered profile handle does not exist.

Open `index.html` in your browser to search GitHub profiles.
