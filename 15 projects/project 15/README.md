# Project 15 Overview

This project is a **Newsletter Subscription UI** built with semantic HTML5, modern CSS3 (custom properties, flexbox, animations), and vanilla JavaScript.

### Features:
- **Interactive Subscription Flow**: Smooth transition between input form and animated subscription confirmation card.
- **Client-Side RFC Validation**: Real-time syntax checking to ensure valid email formats before submission.
- **Duplicate Prevention & Persistence**: Utilizes browser `localStorage` to retain subscriber state and prevent duplicate registrations.
- **Simulated Asynchronous API Service**: Emulates a real-world asynchronous newsletter subscription API with loading spinners and error handling.
- **Dynamic Community Counter**: Automatically increments the live subscriber count upon joining.
- **Unsubscribe & Re-subscribe**: Users can easily unsubscribe directly or subscribe another address.
- **Fully Responsive**: Adapts seamlessly to mobile, tablet, and desktop screens with dark-mode aesthetic.

Open `index.html` in a web browser to run the newsletter app.
