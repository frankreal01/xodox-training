# Project 9 Overview

This project implements a **Contact Form** using plain HTML, CSS, and JavaScript. Features include:
- Form validation with accessible ARIA live region feedback
- Responsive layout for mobile and desktop
- Semantic markup and icons via Font Awesome
- Clear status messages for success or error handling
- No external dependencies beyond the provided stylesheet and Font Awesome CDN

Open index.html in a browser to view and test the contact form.
